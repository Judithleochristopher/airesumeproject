# AI Resume Builder Web Application

A full-stack web app that lets users **generate, customize, and download professional resumes** using an AI-assisted interface. Built with the MERN stack and integrated with ImageKit for profile image uploads and template rendering.

This project demonstrates practical full-stack skills — frontend UI/UX in React, backend APIs in Node/Express, secure data handling, and cloud-ready deployment.

## 🧠 Features

- **AI-Assisted Resume Generation** – Generate sections automatically using smart templates  
- **Multiple Templates** – Choose from sleek, professional resume styles  
- **Profile Image Uploads** – Integrated with ImageKit for optimized image handling  
- **Download as PDF** – One-click resume export  
- **Responsive UI** – Works on desktop & mobile  
- **Secure Auth** – JWT-based login/signup  
- **CRUD Database Support** – Save & manage resumes
